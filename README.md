# Proposta

Este repositório é construído a partir do tutorial disponível no site da microsoft para construção de APIs baseadas em controllers, [link](https://learn.microsoft.com/pt-br/aspnet/core/tutorials/first-web-api?view=aspnetcore-10.0&tabs=visual-studio)

A ideia aqui é que cada branch derivada da develop represente a implementação de algum recurso, as branchs continuam abertas após PR apenas para facilitar o acesso à implementação.

Esse projeto tem o objetivo exclusivo de mostrar a minha evolução no aprendizado da plataforma de desenvolvimento .NET.
